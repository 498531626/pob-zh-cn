# 永恒珠宝天赋漏译修复（2026-11-12）

普通树的 `PassiveContexts` 按原始节点 ID 和原文匹配。永恒珠宝会保留节点 ID，并用 `Data/TimelessJewelData/LegionPassives.lua` 的名称、属性替换或追加原文；这些文本及随机数值原先没有完整接入翻译输入，所以普通天赋覆盖率不能代表变换后天赋的覆盖率。

`export_legion_sources.py` 从当前源码导出瓦尔、卡鲁、马拉克斯、圣堂、永恒帝国五类珠宝的名称和属性，以及 `PassiveSpec.lua` 追加的奉献属性，共 564 条记录。`database_locale.py`、`item_locale.py` 共用这份输入，复用已有中英文参考快照和经过核对的完整词句；补充译文保存在 `legion-reviewed.json`。生成数值模板以匹配随机结果，例如 `+5 to Devotion` 和 `+10 to Devotion` 均可翻译。生成器校验原文仍存在、数字及正负号保持一致。

复现与验证命令（使用可用的 Python 解释器）：

```powershell
python tools/localization/export_legion_sources.py
python tools/localization/build_locale.py
python tools/localization/test_timeless_locale.py
python tools/localization/test_locale.py
python tools/localization/test_calc_panel_locale.py
```

专项 Lua 验证通过 1,193 项名称、原始属性、随机范围两端检查；核对中英文切换、颜色、数值、未知内容回退，以及原始 Legion 数据保持不变。实际 Tooltip:AddLine 路径验证保留原节点 ID 时，标题和 `+10 奉献` 正常翻译，切换语言不会复用错误的缓存。`timeless-pending.json` 为空。原有 11,472 条天赋上下文和 27 项计算面板检查通过。
