# 传奇物品漏译排查

本次检查针对当前 PoB 数据中的传奇药剂、装备和珠宝。所有修改只生成显示词典，不改动物品数据、词缀解析或构筑保存格式。

## 漏译原因与处理

- 静态物品清单及原有运行时快照未采集完整浮窗。药剂基础效果、珠宝授予的天赋说明等文本因此未进入生成器的本地原文集合。现在从真实物品浮窗采集去除颜色和“不支持”后缀的原文，并直接纳入生成输入；`--export-only` 同样采集这些内容。
- 多行属性在拆分前核对整段数值，任意一行不匹配都会提前返回。现在先对齐并分别核对各行，整段和每一行仍各自通过数值检查后才能启用。
- 参考中的 `Bound By Destiny` 与 PoB 的 `Bound by Destiny` 大小写不同。物品名称仅在本地存在唯一对应名称时允许忽略大小写匹配，并补入已核对的“命运的拘束”译名。
- 历史词缀、职业前缀和动态珠宝说明的句式与参考不同。增加有限的完整句式规则，包括药剂使用时获得充能球、至高天赋范围、禁断珠宝匹配词缀、纯才职业条件等。
- 部分中文参考把英文的 `one` 写为数字 `1`，严格数字检查会拒绝，如闪耀精华。此类内容在 `unique-reviewed.json` 中按原文语义单独核对，不放宽自动配对的数字检查。

## 复查

先同步当前源码至独立 QA 副本，再运行：

```powershell
python tools/localization/audit_item_runtime.py --workspace D:/POB/item-translation-qa --export-only
python tools/localization/export_item_sources.py
python tools/localization/build_locale.py
python tools/localization/test_locale.py
python tools/localization/test_unique_locale.py
python tools/localization/test_unique_inventory.py
python tools/localization/audit_item_display.py
# 将新词典同步到独立副本后
python tools/localization/audit_item_runtime.py --workspace D:/POB/item-translation-qa
```

专项测试覆盖译文、范围数值、颜色、英文模式和未知文本回退。全量属性专项要求导出的每条传奇属性在中文显示下不再含英文，同时保留数值、颜色和英文模式。内部物品字段不得作为属性混入清单。实际浮窗审计检查当前物品库及六种制作装备的中文、英文显示，并核对物品序列化与已解析词缀数值保持不变。浮窗审计不是所有旧版变体和任意构筑的界面验收；来源说明、变体标签等界面文字另记录在 `item-runtime-pending.json` 与 `item-display-pending.json`，与属性覆盖分开计数。

原有物品审计仍断言已经移除的中英对照模式，本次改为检查界面实际支持的中文和英文模式。

2026-11-12 补全：上一轮遗留的 1,573 条记录已全部处理，其中 1,569 条显示文本补齐翻译，4 条带缩进的内部字段（等级需求及变体选择状态）从属性采集中移除。另修正冒号字段过滤，保留职业和左右戒指栏位等属性前缀，补查因此新增的 47 条文本。当前导出的 9,231 条传奇属性文本均无英文残留；该检查包含静态历史变体和运行时生成属性，不代表整个界面已无英文。

`item_completion.py` 仅接受可解析为已核对中文名的技能和天赋，组合技能石等级、辅助、星团天赋及条件说明。特殊效果、旧版说明和原始多行属性的分段译文记录在 `unique-extra-reviewed.tsv`，数字以占位符对应英文中的原始顺序；生成器检查来源存在、占位符一致和重复条目。名称大小写的回退仅在译文唯一时启用，数值模板始终匹配完整句子。未核对的新技能名和属性仍保留英文。

验证包括 Python 静态检查、通用及传奇 Lua 专项、全量属性专项，以及 1,338 件实际物品浮窗（含六种制作装备）的保存文本与词缀数值检查。本轮未执行真实窗口人工验收。
