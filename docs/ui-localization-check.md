# 界面文字补漏验证（2026-11-12）

本轮从截图扩大到 Classes、Modules 的界面文字，新增独立的
`interface-ui.json` 和 `interface-formats.json` 输入。涵盖导入分组标题、
默认构筑名、授权与倒计时、空列表说明、编辑框提示、方案管理、删除确认、
导入错误、天赋转换、交易状态和构筑警告。账号、路径、自定义名称和错误详情
作为原始负载保留；内部 ID、输入缓冲区、计算和保存格式不作翻译。

扫描补入 SectionControl、EditControl 的提示参数、defaultText、动态状态、
弹窗调用及跨行拼接。比较时去除颜色标记，避免仅添加颜色就被算作翻译；
多行说明中仍有完整英文行也会进入待检查列表。内部控件名、网络协议、
序列化字段等例外逐条记录在 ui-display-review.json；拼接片段通过完整消息示例验证。

检查范围：

- audit_ui_display.py：界面原文清单及完整消息示例，待检查项为零。
- test_interface_ui.py：完整提示、带颜色及倒计时的授权状态、中文名称、未知错误和英文回切。
- test_locale.py：Lua 翻译、数值与颜色、编辑框及占位提示隔离。
- test_calc_panel_locale.py：计算面板文本。
- test_layout.py：4,214 组标签与宽度、8 个页面、2 种分辨率、语言切换、技能保存及数值一致性。
- 原生窗口抽查：导入页与物品页，确认截图中的标题、默认名称、授权状态、账号提示及空列表说明显示为中文。

此处“待检查为零”指当前扫描规则及列出的完整消息样例，
不代表穷举所有账号响应、第三方错误内容、历史物品数据或全部交互状态。
