# 柳条人脏器显示汉化（2026-11-18）

本轮修复装备页柳条人标题、头部/躯干/手臂/腿部标签、脏器数据库入口和部件名称。`viscera-names.json` 保存当前 164 种不同基础部件的直译（待核对官方译名）；`viscera_locale.py` 从当前 `Data/Viscera.lua` 和 `Data/Bases/wickerman.lua` 检查清单并生成实际低阶/高阶及编号名称，共 447 个名称。名称只进入显示字典，不修改装备 ID、原始英文名称、属性、存档或计算逻辑。生成器遇到新增基础部件或未知阶级会失败，避免静默漏译。

开发模式下未支持属性后附加红色的英文解析片段（字体显示为大写）（`ItemTools.formatModLine`），原先没有匹配到中文数值模板。显示层现在单独识别这个带颜色和引号的诊断片段，对已有数值模板作大小写无关匹配并保留数值、引号、红色和未支持警告；未知内容原样保留。不会改写解析器接收到的属性文本。

专项命令：`python tools/localization/test_viscera_locale.py --workspace <无用户存档的独立副本>`。遍历实际脏器数据构造物品，核对名称、真实 Tooltip 标题、中英切换、截图中的 23%/10 秒属性与开发模式诊断，以及原始物品不变；另运行完整生成和 `check_calc_localization.py`。验收不控制用户桌面，真实窗口视觉检查未进行。

验证结果：完整字典/字形生成成功，新增 457 条显示条目，未删除既有词条或改写其译文。专项通过 441 个实际脏器物品的标题、名称、中英切换、开发模式及原始数据不变检查；447 个不同显示名称由清单覆盖。截图中的高阶炽焰头骨及 23%/10 秒属性诊断复现通过。`check_calc_localization.py` 全部通过（包含本专项），实际计算明细 3,475 条、数值比较 15,994 项、布局 4,221 项。无真实窗口视觉验收。
