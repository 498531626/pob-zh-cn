# 装备词缀汉化补全

2026-11-13，本轮补全普通、魔法、稀有装备相关的制作属性、底材属性、组合属性、前后缀名称和旧版底材名称，并保留此前传奇属性的完整覆盖。

## 范围

| 显示类别 | 源码记录数 |
| --- | ---: |
| 前后缀名称 | 2,152 |
| 底材名称 | 1,094 |
| 底材属性 | 400 |
| 制作属性 | 19,625 |
| 组合制作属性 | 2,051 |
| 物品类型 | 46 |
| 传奇名称 | 1,328 |
| 传奇属性 | 9,231 |

以上按类别分别统计，相同文本在不同类别出现时分别计数。实际浮窗中的来源、变体标签等另行审计，不能把本表的属性覆盖解释为整个应用已经没有英文。

原来的制作采集递归进入了 `weightKey`、`modTags` 等元数据数组，误把权重键、标签及其拼接结果算成词缀。现在仅从真正的词缀记录导出数字下标上的属性文本与 `affix` 显示名，内部字段保持英文且不参与翻译统计。原来 1,221 条制作属性漏项中有 173 条属于此类元数据；2,467 条组合漏项中有 2,002 条属于元数据组合，真实显示漏项继续逐条补全。

## 生成输入

- `craft-extra-reviewed.tsv`：制作、底材、嫁接、星团及历史特殊属性的人工核对译文。数字占位符保留英文原始顺序，中文可以按语义重排。
- `craft-affix-words.tsv`、`craft_affix_names.py`：前后缀名称的词义与有限附魔名称组合。含旧版待修正、未使用标记的条目在中文中保留对应标记；不改动原始英文或内部词缀 ID。
- `craft-names-reviewed.json`：本地仍保留的旧版底材名称。
- `craft-corrections.json`：明确核对过的旧参考分段错误，目前修正技能预付消耗的说明，不覆盖共享名称译法。
- `craft_completion.py`：多行组合、首领条件、嫁接及触发句式；仅使用可解析的已核对内容，不对未知英文词做任意替换。

现有已核对的共享译名保持优先。特殊名称按现有中英文参考和源码语义核对；描述性旧版词缀名不标记为官方配对译名。英文名称大小写差异采用受限句式处理，例如 `Supported/supported`。

## 验证

```powershell
python tools/localization/export_item_sources.py
python tools/localization/build_locale.py
python tools/localization/test_locale.py
python tools/localization/test_item_inventory.py
python tools/localization/test_unique_inventory.py
python tools/localization/audit_item_display.py
python tools/localization/audit_item_runtime.py --workspace D:/POB/item-translation-qa
```

全量专项通过实际 Lua 显示层检查名称和属性有无英文残留、数值、颜色、英文切换及未知内容回退。既有译文把英文不定冠词或逐项单位写成数字“一”时，只对对应的计数单位进行等义归一，不放宽百分比或其他玩法数值检查。

实际浮窗审计使用独立副本，检查 1,338 件物品（含六种制作装备）的保存原文和已解析词缀数值在中英文下保持不变。静态源码清单覆盖历史文本，实际浮窗样本不代表所有旧版变体与任意构筑的界面验收；本轮未做真实窗口人工验收。
