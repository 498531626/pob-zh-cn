Destructive Link
Critical, Spell, Duration, Link
Level: (1—20)
Cost: (15—32.67) Mana per second
Cast Time: 0.50 sec
Requires Level (34—70), (35—68) Dex, (50—98) Int
Targets an allied player to apply a buff which links you to them for a duration. While linked, they use your main hand critical strike chance. If the target dies while linked, you will also die. This skill cannot be triggered, or used by Totems, Traps, or Mines.
Base duration is (8—9.9) seconds
Linked target has +(30—49)% to Critical Strike Multiplier
Linked target's Main Hand Critical Strike Chance is equal to yours
Link breaks if target leaves range or line of sight for 4 seconds
Maximum 1 Link from any source per target
You die if Linked target dies

Additional Effects From Quality:
+(0—1.5) seconds to Base duration
Place into an item socket to gain this skill. Right click to remove from a socket.
