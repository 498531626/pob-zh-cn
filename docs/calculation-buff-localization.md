# 计算页增益列表翻译修复

`Calcs.lua` 使用英文名称生成 `BuffList`、`CombatList`。旧显示逻辑只在
整份列表的每一项均命中词典时翻译，`Spectre` 或未收录的计数增益会令
整栏回退英文。`5 Inspiration Charges` 还缺少复数名称的词典条目。

现在在 `CalcFormat.lua` 的两个列表输出处调用显示层逐项翻译，未知项仅
保留自身英文。角色与召唤物使用相同路径；计算输出、键名、数值及保存
数据仍是原始内容。补入 14 个显示名称，支持能量球、幽魂缠身、深海屏障
和精魂灌注的数量，以及已知技能与灵体名称组合的来源说明。

验证范围：

- `test_calc_buff_lists.py`：截图列表、全部 56 处战斗增益输出标签、未知项、
  颜色、角色与召唤物、英文回切、空列表和计算输出隔离。
- `test_calc_panel_locale.py`、`test_locale.py`：现有计算面板及汉化回归。
- `test_layout.py`：独立副本的 4,214 组宽度检查、8 页、2 种分辨率，
  核对语言切换后的计算数值和技能序列化一致。
- 原生窗口：使用截图文字构造显示样例，检查中文、英文、未知项与来源名称。
  这属于原生绘制抽查，未使用用户原始构筑文件进行完整构筑回归。

上述回归在隔离本次改动的副本执行；共享工作区的其他界面及制作词缀
修改不属于本次提交。
