    Detonate Mines

    Detonate Mines is a skill gem that performs the same function as the gem-less detonate skill that is automatically made available when a player has used a mine. Unlike detonating mines using the hotkey, the Detonate Mines skill gem can take advantage of mechanics afforded by being linked to support gems.

    Skill functions and interactions

    • Detonate Mines is a colourless gem and can be placed into any item socket.

    • Trigger Gems : Detonate Mines can be linked to trigger gems like Cast when Damage Taken Support or Spell Totem Support to allow the player to detonate mines without need to manually use a key.
