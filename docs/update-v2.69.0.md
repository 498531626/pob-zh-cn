# v2.69.0 汉化适配（2026-11-27）

官方稳定版：[v2.69.0](https://github.com/PathOfBuildingCommunity/PathOfBuilding/releases/tag/v2.69.0)，GitHub 发布于 2026-11-25。从 v2.68.1 正常三方合入，共 131 个官方文件变化。汉化版本重置为 `2.69.0.1`。

保留新版配装管理服务、灵体分类／推荐与尸体筛选、12 种排序、怪物属性与出现地点、物品图标及已装备标记、脏器外观和计算修复。处理 6 处冲突：更新记录、版本清单、控件 Tooltip 焦点规则、下拉详情隐藏、列表图标留白及中文截断、灵体标题。避免物品过滤器将新版 Manage 操作当成配装方案。

补充配装管理弹窗与配置／物品／技能组操作、灵体分类与排序、生命／魔力保留效能、血肉撕裂层数、盐水球与近期反击条件等中文。显示层不修改计算键名、怪物／区域／宝石 ID、排序数值、英文解析和构筑格式。灵体名称保持专用上下文，避免 Necromancer 怪物与升华职业译名相互覆盖。灵体名称与技能均支持中英文检索；中文标题限制在现有属性栏宽度内。

游戏专名先查流亡编年史。辅助宝石输入见 `tools/localization/upstream-2690-gem-names.json`；灵体及技能核对见 [术语核对记录](upstream-2690-term-review.md)。额外 72 个地点逐页查找，71 个按实际区域 ID 或唯一对应卡片配对；`Blackguard Salute` 的精确页面返回 404，站点检索未找到对应记录，保留直译并标记未匹配，不能据此声称编年史没有译名。缓存与查找证据保存在 `tools/localization/area-reference/`、`spectre-area-reviewed.json`。

天赋仍为 3.30；运行库、TreeData 和 GameVersions 与官方 tag 一致，本轮不变。重新导出实际物品、运行时特殊物品、静态数据库和永恒珠宝显示清单；新增世界区域文本只用于显示，不修改官方数据。

统一生成 45,938 个词条、2,628 个中文字符。灵体名称表的 1,578 个独立名称均有双语参考配对；新增核对的 247 项没有继续使用直译。13 个宝石名称均有卡片参考。177 个新补技能显示名中，175 项在查找后直译、2 项采用同名术语语义参考，未将其他技能变体冒充同 ID 配对。地点覆盖 350 种完整标签、322 个基础名称，1 个基础名称保留有查询记录的直译。
