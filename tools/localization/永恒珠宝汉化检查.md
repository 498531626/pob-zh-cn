# 永恒珠宝天赋漏译修复（2026-11-12）

普通树的 `PassiveContexts` 按原始节点 ID 和原文匹配。永恒珠宝会保留节点 ID，并用 `Data/TimelessJewelData/LegionPassives.lua` 的名称、属性替换或追加原文；这些文本及随机数值原先没有完整接入翻译输入，所以普通天赋覆盖率不能代表变换后天赋的覆盖率。

`export_legion_sources.py` 从当前源码导出瓦尔、卡鲁、马拉克斯、圣堂、永恒帝国五类珠宝的名称和属性，以及 `PassiveSpec.lua` 追加的奉献属性，共 564 条记录。`database_locale.py`、`item_locale.py` 共用这份输入，复用已有中英文参考快照和经过核对的完整词句；补充译文保存在 `legion-reviewed.json`。生成数值模板以匹配随机结果，例如 `+5 to Devotion` 和 `+10 to Devotion` 均可翻译。生成器校验原文仍存在、数字及正负号保持一致。

复现与验证命令（使用可用的 Python 解释器）：

```powershell
python tools/localization/export_legion_sources.py
python tools/localization/build_locale.py
python tools/localization/test_timeless_locale.py
python tools/localization/test_locale.py
python tools/localization/test_calc_panel_locale.py
```

专项 Lua 验证通过 1,193 项名称、原始属性、随机范围两端检查；核对中英文切换、颜色、数值、未知内容回退，以及原始 Legion 数据保持不变。实际 Tooltip:AddLine 路径验证保留原节点 ID 时，标题和 `+10 奉献` 正常翻译，切换语言不会复用错误的缓存。`timeless-pending.json` 为空。原有 11,472 条天赋上下文和 27 项计算面板检查通过。

本轮原生测试窗口启动后未获得有效绘制结果，截图为黑屏，因此真实窗口验收未完成。上述专项检查不代表遍历了所有种子和珠宝组合，也不包含新增深渊珠宝数据。


## 新增珠宝查询选项（2026-11-18）

此前的导出与专项测试按五种旧珠宝的 ID 前缀筛选，未覆盖卡古尔和深渊系列。因此旧版测试通过、待译清单为空，也不能代表新增珠宝已经汉化。本轮取消前缀白名单，导出当前 LegionPassives 的全部名称和属性，加上运行时 `AbyssNotableNames.lua` 的简称，共 1,615 条来源记录；弹窗测试遍历全部 11 类珠宝，核对征服者、奉献词缀、所需升华结果、排序、节点及属性组合文本，并验证中文搜索和中英文切换不改变源标签、内部 ID、选中项或原始属性。

新增卡古尔和深渊专属名称、运行时简称及部分属性采用按原意直译，保存在 `legion-reviewed.json`，尚未逐条核对官方中文名；其中 `Notable N` 是上游占位名称，显示为“核心天赋 N”，保留编号。新增征服者组合标签和“镶嵌珠宝”标签保存在 `tree-detail-ui.json`。“Socket Jewel”表示同时装备搜索结果中的珠宝，并非插槽等级。

验证使用独立副本及无界面 Lua 绘制调用，不控制用户桌面，不代表真实窗口视觉验收或全部种子的计算回归。复现弹窗检查：`python tools/localization/test_timeless_socket_locale.py --workspace <无用户存档的独立副本>`；同时运行全量来源专项 `test_timeless_locale.py` 及项目要求的 `check_calc_localization.py`。

本轮验证结果：`build_locale.py` 完整生成成功；`test_timeless_locale.py` 通过 3,248 项名称/属性/范围端点检查；弹窗通过 1,926 项节点与语言组合、66 项插槽与语言组合检查，以及全部 11 类珠宝的相关下拉选项。`check_calc_localization.py` 全部通过，包括 2,302 项计算标识符、3,475 条实际明细文本、15,994 项数值比较、导入装备与 4,221 项布局检查。未进行真实窗口视觉验收。
