    Kitava's Thirst

    Mechanics

    • 50% chance to Trigger Socketed Spells:
      • Each time you use a skill with a mana cost of 100 or higher, there is a 50% chance all socketed spells will trigger. Typically only one spell can be triggered at a time, which makes this item more unique.
      • If multiple of the same spell skill gem are socketed, only one will trigger. For example, if two Summon Raging Spirit skill gems are socketed, only one will cast.
    • when you Spend at least 100 Mana:
      • 100 or more mana must be spent in order to trigger socketed spells.
        • 100 mana must be spent all at once, not across multiple uses.
        • Skills cast with life via Blood Magic or energy shield via Eldritch Battery will not trigger socketed spells.
        • Using Soul Taker or other methods that avoid mana costs will not trigger socketed spells.
        • Mana reservation can trigger socketed spells.
    • Use a Skill:
      • Channeled skills with a mana cost of 100 or above can only trigger spells with the initial cast. This is because Kitava's Thirst triggers when spending mana to use a skill, not to maintain an already-used skill.
    • Targeting
      • Triggered spells will target a nearby target. The triggered spells will not necessarily target the same location or enemy targeted by the original skill.
      • If there are no nearby potential targets, the casts will target randomly.
