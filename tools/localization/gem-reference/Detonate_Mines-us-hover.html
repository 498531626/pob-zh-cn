Detonate Mines
Mine, Spell
Cooldown Time: 0.20 sec
Cast Time: Instant
Requires Level 8, 0 Str, 0 Dex, 0 Int
Detonates a Mine, starting a Detonation Sequence which will detonate other Mines around it.
First Mine Detonates Instantly
Mines get 10% more Detonation Speed for each prior Mine in Detonation Sequence

Additional Effects From Quality:
Mines have (0—20)% increased Detonation Speed
Place into an item socket to gain this skill. Right click to remove from a socket.
