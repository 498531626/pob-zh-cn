# v2.68.1 汉化适配

官方稳定版：https://github.com/PathOfBuildingCommunity/PathOfBuilding/releases/tag/v2.68.1 。从 v2.68.0 正常三方合并，无冲突。

上游仅修改物品页数据库布局及发布清单/更新说明，共 4 个文件。修复大屏幕下数据库选择器隐藏、无法选择脏器列表的问题，保留中文控件和边界绘制接入。本版无新增英文显示词条，继续使用现有“脏器”等译名。游戏数据、3.30 天赋和运行库没有变化，无需刷新参考快照；重新生成汉化资源和版本元数据。

扩展隔离布局测试：1280×720、1920×1080、2560×1440，各以中文、英文、回切中文检查全部三种物品数据库，确保选择器可见、仅目标列表显示、原始英文列表键不变，计算值和技能保存数据不变。同一测试在旧版能复现选择器隐藏问题，新版通过。

完整生成后专项通过：2,302 个计算属性名称；3,475 条实际计算文本无待翻译项；15,994 次数值比较；4,221 组宽度检查、8 个页面、3 种分辨率及全部数据库切换；472 种涂油配方、魔法物品导入、传奇不支持效果提示和构筑保存检查。覆盖统计与 v2.68.0 一致。重新生成只改变部分等价引用来源的选择，已确认译文、类别和状态相同，沿用既有来源记录以避免无关差异。所有测试使用隔离副本和无界面脚本；未进行真实窗口人工验收。用户构筑、设置、语言选择和外层官方便携目录不参与更新。未推送或发布。其余未核对历史/特殊词条的覆盖边界仍以 v2.68.0 更新记录为准。
